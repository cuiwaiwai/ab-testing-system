# 🧪 A/B测试实验设计与分析系统

专业的 A/B 测试实验设计与分析工具，覆盖从实验设计、数据导入、描述统计、假设检验到决策建议的完整工作流。

## ✨ 功能模块

| 模块 | 功能说明 |
|------|----------|
| 🎯 **实验设计** | 样本量计算（比例型/均值型）、统计功效分析 |
| 📥 **数据导入** | 多格式数据上传（CSV/Excel）、示例数据生成、手动输入 |
| 📊 **描述统计** | 分组描述分析、分布对比、转化率对比 |
| 🧪 **假设检验** | t检验、比例Z检验、卡方检验、Mann-Whitney U检验 |
| 📈 **结果可视化** | 分布图、均值比较、累积提升、置信区间 |
| 📋 **决策建议** | 基于显著性和效应量的四象限决策框架 |

## 🎨 特色功能

- **7 套自定义配色方案**：多巴胺色系、莫兰迪色系、绿色清新、粉色、紫色、黑色、白色
- **首页详细理论讲解**：包含实验设计、假设检验、效应量与功效、方法选择指南
- **输出区域高亮提示**：所有分析结果都有醒目的视觉标识
- **窄化侧边栏设计**：更大的内容展示空间

## 🚀 本地运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
streamlit run app.py
```

### 3. 访问

浏览器打开 http://localhost:8501

## 🌐 局域网访问

让同一 WiFi 下的其他人访问：

```bash
streamlit run app.py --server.address 0.0.0.0
```

然后其他人访问 `http://<你的IP地址>:8501`

## 📖 使用指南

1. **实验设计** → 先计算所需样本量，确定实验规模
2. **数据导入** → 上传实验数据或生成示例数据
3. **描述统计** → 查看两组的基础统计特征
4. **假设检验** → 选择合适的统计检验方法
5. **结果可视化** → 通过图表直观理解差异
6. **决策建议** → 结合显著性和业务意义做出决策

## 🛠️ 技术栈
